# Release repository for the rewire ROS 2 package

This is the [bloom](https://github.com/ros-infrastructure/bloom) release repository for [`rewire`](https://github.com/rewire-run/rewire-ros), the ROS 2 package that starts the [rewire](https://rewire.run) bridge from `ros2 launch`. The ROS build farm reads the branches here to build `ros-<distro>-rewire` for packages.ros.org.

Everything except `tracks.yaml` is generated by bloom from a tagged release of the source repository. Do not edit the generated branches by hand. Bugs, features and changes belong in the [source repository](https://github.com/rewire-run/rewire-ros).

## Layout

- `master` holds `tracks.yaml`, one track per ROS distribution, all pointing at the source repository's `main` branch and its `v<version>` tags.
- `upstream` holds the imported source of the last release.
- `release/<distro>/rewire/<version>` is the release branch per distribution.
- `debian/<distro>/<platform>/rewire` holds the generated Debian packaging the build farm consumes.

RPM generation is left out on purpose. The bundled binary targets a newer glibc than RHEL ships.

## Releasing

From a machine with `python3-bloom` and an up-to-date rosdep database:

```bash
bloom-release --rosdistro humble --track humble rewire_ros
```

bloom asks whether to restore its default actions because the RPM generators are removed here. Keep the current actions. Repeat per distribution. The full procedure lives with the source repository.
